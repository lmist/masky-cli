# Command reference

Generated by `go run ./cmd/docs`. Do not edit by hand.

All commands accept the global flags below. JSON is the default output; `--format table` is optional.

```text
      --allow-insecure           Allow remote HTTP URLs; HTTPS is the default
      --base-url string          API base URL (or MASKY_BASE_URL)
      --config string            Config file (or MASKY_CONFIG)
      --dry-run                  Validate and print a redacted HTTP request without sending it
      --error-format string      Error output: text or json (default "text")
      --force                    Allow replacing output files
      --format string            Output format: json or table (default "json")
      --poll-interval duration   Time between job polls (default 2s)
      --profile string           Profile (or MASKY_PROFILE; default: active profile)
      --raw                      Print a selected scalar without JSON quoting
      --retries int              Retries for transient GET failures only (0–10) (default 2)
      --save-json string         Write output privately to a file instead of stdout
      --select string            Select a dot-separated JSON path (e.g. avatars.0.avatarId)
      --timeout duration         Timeout for each HTTP request (default 2m0s)
      --wait-timeout duration    Total time allowed for polling (default 10m0s)
  -y, --yes                      Confirm revocations, deletion, tribe fees, or gift confirmation
```

## `masky api`

Call a relative API path directly

```text
masky api <method> <path> [flags]
```

Call a path relative to the selected API base URL. This escape hatch skips endpoint validation.
Writes are never retried. DELETE requires --yes. Use --anonymous for public routes.
Example: masky api GET /avatars

```text
      --anonymous           Do not send authorization
      --data string         JSON object, @file, or - for stdin
      --query stringArray   Query parameter key=value (repeatable)
```

## `masky completion bash`

Generate the autocompletion script for bash

```text
masky completion bash
```

Generate the autocompletion script for the bash shell.

This script depends on the 'bash-completion' package.
If it is not installed already, you can install it via your OS's package manager.

To load completions in your current shell session:

	source <(masky completion bash)

To load completions for every new session, execute once:

#### Linux:

	masky completion bash > /etc/bash_completion.d/masky

#### macOS:

	masky completion bash > $(brew --prefix)/etc/bash_completion.d/masky

You will need to start a new shell for this setup to take effect.

Not lip-synced (use a speak turn for talking to camera). Async: returns 202, then poll GET /videos/{generationId}. Every render gets a /v-yy-mm-xxxx share page.       --avatar-id string          One of your avatars (404 otherwise). With image omitted the clip opens on its primary still. Required for speechText
